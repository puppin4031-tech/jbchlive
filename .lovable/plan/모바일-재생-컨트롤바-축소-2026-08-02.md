# 모바일 재생 컨트롤바 축소

## 왜 지금은 변화가 없나

모바일에서 구글드라이브 영상은 브라우저(OS) 기본 `<video controls>` 를 씁니다. 이 컨트롤바는 브라우저가 직접 그리는 UI라 CSS/Tailwind로 크기를 바꿀 수 없습니다. 지난번 축소는 우리가 만든 오버레이(새 창 열기, 로딩, 오류 패널)에만 적용돼서 체감 차이가 없었습니다.

데스크탑 드라이브 재생은 iframe(구글 페이지) 이라 마찬가지로 컨트롤 크기를 바꿀 수 없습니다.

## 해결 방법

`controls` 속성을 끄고, 우리가 직접 그린 컨트롤바를 영상 위에 올립니다. 그러면 크기를 자유롭게(기본 대비 약 60% 크기로) 조절할 수 있습니다.

적용 범위: 모바일에서 네이티브 `<video>` 로 재생되는 경우 — 구글드라이브 영상, 직접 URL/HLS 영상.

## 커스텀 컨트롤바 구성

- 재생/일시정지 버튼
- 진행 바 (드래그로 탐색) + 현재시간 / 총시간
- 음소거 토글
- 전체화면 버튼 (OS 전체화면 API 사용 — 전체화면 진입 시에는 기기 기본 컨트롤로 전환되어 회전·터치 최적화 그대로 유지)
- 3초간 조작이 없으면 자동으로 숨김, 화면 탭하면 다시 표시

크기 기준(기본 대비 약 60%): 아이콘 16px, 바 높이 약 32px, 진행 바 두께 3px, 시간 텍스트 10px, 좌우 여백 8px.

## 기술 메모

- 수정 파일: `src/components/VideoPlayer.tsx`
- 컨트롤 UI는 `src/components/VideoControls.tsx` 로 분리 (video ref 를 받아 재생상태·시간·음량을 구독)
- 모바일에서만 커스텀 컨트롤 사용, 데스크탑은 기존 그대로 유지
- `playsInline` 유지 (iOS에서 인라인 재생), 전체화면은 `requestFullscreen` / iOS는 `webkitEnterFullscreen` 폴백
- HLS 라이브 재생 시에는 총시간 대신 "LIVE" 뱃지 표시, 진행바 숨김
