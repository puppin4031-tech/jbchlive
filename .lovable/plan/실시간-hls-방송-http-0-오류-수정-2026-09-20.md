# 실시간 HLS 방송 `http: 0` 오류 수정

## 확인된 원인
- 오류는 Google Drive VOD가 아니라 Google 저장소의 실시간 HLS 방송에서 발생합니다.
- master manifest, 영상·오디오 목록, 영상 조각은 모두 HTTP 200으로 정상 생성됩니다.
- 저장소 응답에 브라우저 교차 출처 허용 헤더가 없어, 플레이어가 정상 응답을 읽지 못하고 `networkError / http: 0`으로 처리합니다.
- DB는 `STREAMING`이고 방송 주소도 정확하므로 OBS, GCP 채널/Input, mux, 파일 생성 문제는 아닙니다.

## 변경 내용
1. 기존 출력 버킷 준비/복구 과정에 HLS CORS 설정을 적용합니다.
   - 게시 사이트, 미리보기 사이트, localhost 허용
   - `GET`, `HEAD` 허용
   - Range 재생에 필요한 응답 헤더 노출
2. 방송 프로비저닝 시 공개 읽기 권한과 CORS 설정을 각각 확인합니다.
3. 관리자 출력 버킷 복구 기능이 현재 버킷의 CORS를 즉시 교정하도록 합니다.
4. 관리자 진단 화면에 공개 접근 상태와 CORS 상태를 별도로 표시합니다.
5. 방송 함수를 배포하고 현재 버킷 복구를 실행한 뒤 manifest, 하위 목록, 영상 조각의 응답 헤더와 실제 재생을 검증합니다.

## 보호 범위
- 방송 시작·종료 흐름, OBS 주소, GCP Channel/Input 생성 방식, 저장 경로는 변경하지 않습니다.
- 영상은 계속 Google 저장소에서 시청자에게 직접 전달합니다.
- 현재 방송 파일을 삭제하거나 방송을 재시작하지 않습니다.
