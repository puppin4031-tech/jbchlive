# 구글 로그인 계정 선택 + 관리자 채널별 사용량/비용 대시보드

## 목표
1. 구글 로그인 시 최근 계정 자동 로그인 대신 **계정 선택창**이 항상 뜨도록 변경
2. 관리자 페이지에서 **채널별 송출 통계와 GCP Live Stream 추정 비용(원화)** 확인

## 1. 구글 로그인 계정 선택
- `src/pages/LoginPage.tsx`의 `lovable.auth.signInWithOAuth('google', ...)` 호출에 `extraParams: { prompt: 'select_account' }` 추가
- 이미 로그인된 구글 세션이 있어도 매번 계정 선택 화면이 표시됨

## 2. 관리자 채널별 송출 통계 + 비용 추정

### 데이터 소스 (마이그레이션 불필요 — 기존 테이블 활용)
- `live_sessions`: 채널별 방송 횟수, `duration_seconds`(송출 시간), `avg_viewers`, `peak_viewers`, `started_at`
- `live_viewer_samples`: 분당 시청자 수 스냅샷 → 정확한 "시청자·시간(viewer-hours)" 계산
- 관리자는 기존 RLS 정책으로 두 테이블 모두 읽기 가능 (`has_role(admin)` 정책 존재 확인 완료)

### 신규 파일
- `src/lib/gcpCostEstimate.ts` — 비용 추정 상수 및 계산 함수 (상수는 한 곳에 모아 조정 쉽게)
  - 현재 채널 설정 확인 완료: **1280x720 (HD 720p)**
  - **방송국 가동 비용(인코딩): $1.08/시간** — 시청자 수와 무관, 방송 시간(duration)만큼 청구
  - **시청자 트래픽 비용(egress): $0.12/GB** — 시청자 1명·1시간 시청 시 약 **1GB** 소모 기준
  - 환율: USD→KRW 기본 **1,350원** (관리자 화면에서 입력으로 조정 가능, 로컬 상태)
  - 참고 예시 (사용자 검증 모델): 주일 90분 × 월 4회, 20명 시청 → 가동비 $6.48 + 트래픽 $14.40 = **$20.88/월 ≈ 28,000원**
- `src/components/admin/ChannelUsagePanel.tsx` — 채널별 통계/비용 테이블
  - 채널별: 총 방송 횟수, 총 송출 시간, 평균 시청자, 최고 시청자, 시청자·시간, 추정 송출량(GB), **추정 비용(₩)**
  - 기간 필터: 이번 달 / 지난 달 / 전체
  - 상단에 전체 합계 카드 (총 추정 비용 원화)
  - 하단 안내 문구: "GCP 콘솔 청구액과 차이가 있을 수 있는 추정치입니다 (단가·환율 기준 표시)"

### 수정 파일
- `src/pages/AdminPage.tsx` — 탭 목록에 "사용량/비용" 탭 추가, `ChannelUsagePanel` 렌더링

### 계산 방식
```text
인코딩 비용 = Σ(세션 duration_seconds) ÷ 60 × $0.15  (HD 720p 기준)
송출 비용   = Σ(시청자·시간) × 0.73 GB × $0.12
총 비용(₩) = (인코딩 + 송출) × 환율
```

## 검증
- 로그인 페이지에서 구글 로그인 시 계정 선택창 표시 확인
- 관리자 페이지 새 탭에서 채널별 통계와 원화 추정 비용이 표시되는지 확인
- 타입체크/빌드 통과 확인
