# 썸네일 압축 강화 + 추천 구간 고정

## 목표
1. 영상 업로드 시 직접 올린 썸네일 이미지를 더 강하게 압축(품질 70%)한다.
2. 자동 썸네일 추천 구간을 비율(1%/25%/50%/75%)이 아니라 **3초, 50초, 5분, 20분** 고정 지점으로 바꾼다.

## 변경 내용

### 1) 이미지 압축 70%
`src/lib/imageCompress.ts`
- 기본 품질을 0.82 → 0.70으로 변경하고, 목표 용량 미달 시 재시도 단계도 0.7 → 0.6 → 0.5 → 0.4 순으로 정리.
- 최대 크기(1280px)와 JPEG 출력은 그대로 유지.
- `ThumbnailPicker`는 이미 이 함수를 쓰므로 추가 수정 불필요.

### 2) 자동 추천 구간 고정
`src/lib/thumbnailUtils.ts` 의 `captureVideoThumbnails`
- `percentages = [0.01, 0.25, 0.5, 0.75]` 제거.
- 고정 시점 `[3, 50, 300, 1200]`(초) 사용.
- 영상 길이보다 긴 시점은 건너뛰고, 유효 시점이 하나도 없으면 영상 길이의 10% 지점 1장만 캡처.
- 나머지 로직(seeked 캡처, 15초 타임아웃, CORS 실패 시 빈 배열)은 유지.

## 참고
- YouTube/구글드라이브 링크는 플랫폼이 제공하는 썸네일을 쓰므로 이번 변경은 직접 재생 가능한 영상(mp4 등)에만 적용됩니다.
